FOS v1.0
Free Open System

An open-source command-line social/file platform.

Commands:
 /create <Username> <Password> [Email]
 /login <Username> <Password>
 /logout
 /upload <File Path> <Details.txt Path>
 /load <File/Plugin/Profile> <Subject ID Or Name>
 /view <File/Profile> <Subject ID Or Name>
 /page <Create/Edit/Delete> <Page.zip Path>
 /template <Use> <Template>
 /chat <New/Close/Resume> ...
 /server <Create/List/Join/Leave>
 /friend <Add/Remove/List>
 /plugin <Enable/Disable/Delete> <Plugin Name Or ID>
 /settings
 /help
 /exit

FOS v1 file limit:
10 bytes minimum
100 MB maximum

FOS is open source. Do not install untrusted plugins.
